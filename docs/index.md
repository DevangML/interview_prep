## 🚀 Quick Start Guide

### 1. Run the Senku Socratic REPL CLI
```bash
# Run default turn
python3 senku_cli.py

# Pass custom prompt
python3 senku_cli.py "Explain memory layout of dynamic arrays"
```

### 2. Execute the Test Suite
```bash
python3 -m unittest test_okf_engine.py
```
