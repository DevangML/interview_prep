% ------------------------------------------------------------ SIDE PROJECTS
\section*{Side Projects}

\begin{itemize}
  \item \textbf{AI Operating System --- a generic spec-driven delivery framework.} Built from one observation: agent-assisted delivery fails less from weak models than from weak constraints. Each layer answers a failure mode I hit in practice. \textit{Agents inventing requirements} $\rightarrow$ a constitution layer where every change maps to a stated acceptance criterion, and nothing is called done on its first pass. \textit{One generalist agent producing shallow work} $\rightarrow$ an orchestrator composing 2--4 specialist roles per delivery dimension (quality, tests, architecture, adversarial review). \textit{Unverifiable completion} $\rightarrow$ a layered model from test harness to ship, gated by verification batches whose trace rows flip only when exit tests pass. \textit{Context burned on blind code search} $\rightarrow$ a retrieval hierarchy putting structured artefacts and a code knowledge graph ahead of scanning. \textit{Improvements getting lost} $\rightarrow$ an experiment loop that seals proven wins back into the rules layer, so the framework tightens itself.
  \item \textbf{Adaptive Learning System --- self-healing agent control loop.} A SENSE $\rightarrow$ COMPARE $\rightarrow$ DIAGNOSE $\rightarrow$ ADAPT $\rightarrow$ ROLLOVER loop where an agent reads a nightly six-field log, diagnoses drift against plan and re-sequences the next day; spaced repetition, interleaving and leech rules encoded as planner invariants.
\end{itemize}
