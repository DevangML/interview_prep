# The Drill Loop

**Two files.** `targets.html` is the answer key — open it in a browser. `blank.html` is where you type.

```
1. LOOK    open targets.html, study ONE archetype           30 sec
2. CLOSE   close the tab. Actually close it.
3. TYPE    blank.html, from memory, timer running           see target time
4. CHECK   the 4 checks below                               60 sec
5. LOG     one line per miss. Nothing else.
```

## The 4 checks — same every time, no thinking required

```
□ TAB through it. Every control reachable? Focus ring visible?
□ Narrow the window to 375px. Any horizontal page scroll?
□ Console open. Clean?
□ Every button/input have a name? (icon buttons need aria-label, inputs need <label>)
```

## Copy this into blank.html's <style> — from memory, every single time

The preamble is 5 lines and it is the difference between a build that passes the
keyboard check and one that doesn't. Typing it is part of the drill.

## Order

Do them in this order. Each one reuses the previous one's muscles.

`1 centered box (2m)` → `4 card grid (90s)` → `2 action bar (3m)` → `3 data list (3m)`
→ `10 state triad (2m)` → `5 app shell (5m)` → `6 modal (3m)` → `7 form (4m)`
→ `8 table (4m)` → `9 tabs (4m)` → **composition (12m)**

## When you can do all 10 inside target time

Stop drilling individually. Only run the composition: shell + action bar + card grid + state
triad, 12 minutes, blank file. That is the actual interview shape.
