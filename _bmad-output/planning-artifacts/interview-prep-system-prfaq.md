## Internal FAQ

### Q: What is the underlying technical architecture of the Teach-Me AI Learning Engine and how does it integrate with Frappe/Liberoid/BMad?

A: The Teach-Me engine is implemented as a Liberoid Agent Orchestrator inside the Frappe/Liberoid framework, backed by the local BMad skill suite. It defines specialized agents (Senku Scientific Lead, Jesus Encourager/Mentor, OKF Memory Manager, and BMad Enrichment Router). The orchestrator executes custom Python code (`orchestration_code`) to manage dialog turns, context retrieval, persona blending, and state synchronization.

### Q: How does the OKF (Optimized Knowledge Format) stateful memory model work algorithmically?

A: OKF is a structured, hierarchical JSON/YAML AST representing a candidate's Knowledge Graph. It organizes domains (DSA, System Design, Math, HR) into nested nodes containing `concept_id`, `mastery_score` (0.0–1.0), `error_patterns` (list of recurring missteps), `last_reviewed`, and `next_decay_date` (Ebbinghaus forgetting curve logic). On every conversation response:
1. The OKF Memory Manager parses the turn output for concept references and mastery indicators.
2. It executes a differential update to the tree.
3. It compresses the tree into a deterministic snapshot hash and saves it via Frappe/MCP doc store.
4. The next prompt injects only the relevant active branch of the OKF tree, keeping token consumption minimal (<500 tokens) while preserving complete historical context.

### Q: How does the BMad Context Enrichment Pipeline utilize *every* installed BMad skill without causing prompt overload or latency spikes?

A: The pipeline uses a dynamic Skill Router (`bmad-enrichment-router`). Rather than dumping all skill prompts simultaneously, it dynamically triggers skills based on the interview prep phase:
- **DSA/Coding Phase**: Invokes `bmad-review-edge-case-hunter` and `bmad-code-review`.
- **System Design Phase**: Invokes `bmad-architecture`, `bmad-spec`, and `bmad-review-adversarial-general`.
- **HR & Narrative Phase**: Invokes `bmad-cis-storytelling` and `bmad-prfaq`.
- **Strategic Direction & Ideation**: Invokes `bmad-brainstorming` and `bmad-forge-idea`.
The router runs subagent evaluations asynchronously or in pre-execution hooks, injecting enriched context only when relevant.

### Q: What is the biggest failure risk of the Teach-Me Engine, and how is it mitigated?

A: The biggest risk is **Persona Sycophancy**—where the AI persona becomes too lenient, praising incorrect candidate explanations or failing to spot subtle algorithmic flaws. This is mitigated by combining the Senku persona prompt with strict unit testing & verification scaffolds: candidate solutions are executed against actual test runners (or Python REPL execution environments) to verify time/space efficiency and functional correctness before Senku grants mastery approval.

### Q: How do we measure the candidate's actual progression across the 3-month timeline?

A: Progress is tracked via automated OKF Analytics dashboard:
- **Mastery Velocity**: Rate of concept node progression from `Unlearned` -> `Socratic Review` -> `Mastered`.
- **Retention Score**: Performance on decayed OKF concepts re-tested after 7, 14, and 30 days.
- **Mock Interview Scorecard**: Automated evaluation using BMad Rubrics across Problem Solving, Communication, Code Quality, and System Scalability.

### Q: What resources are required to run this locally, and what are the system dependencies?

A: The system runs locally on standard developer hardware (macOS zsh environment). Dependencies include Python 3, Frappe Bench / Liberoid environment (or standalone Node/Python orchestrator), and access to Gemini 1.5 Pro / Claude 3.5 Sonnet APIs via standard MCP endpoints. Local memory state is stored in standard JSON/YAML file format under the workspace `.agents` or `_bmad-output` directory.
