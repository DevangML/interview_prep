# Answer contract

The museum is an evidence reader, not an authority oracle. For each selected record or answer generated from the corpus, render a compact evidence envelope:

| Field | Rule |
| --- | --- |
| Who said this | Record `origin.summary`, plus source host/title when available. Never turn an unresolved origin into a named inventor. |
| Authority | A provisional 1–10 score for the strongest supporting source. Normative specification/standard: 10; peer-reviewed primary paper: 9; maintained official language/runtime documentation: 8; official vendor guidance: 6; survey/encyclopedia: 5; blog/forum/uncurated lead: 2. No source: 0. |
| Confidence | Preserve corpus confidence and status. Explain whether it reflects mechanism evidence, attribution, or language support. |
| Reasoning chain | `problem → mechanism → solutionFamily → costs → transferRule`; source links sit beside the mechanism, not after an unsupported conclusion. |
| Exhaustiveness | Give the bounded release denominator and say what the record does not cover. “Exhaustive” is scoped to the release only. |
| Further research | Name unknown language cells, unresolved attribution, source promotion, and relevant research documents. |

The authority score is evidence-tier metadata generated by the adapter. It is not an estimate of the intellectual worth of an author and is not a substitute for expert review. If multiple sources disagree, show the disagreement and lower confidence rather than averaging it away.
